Qwen2.5-VL-style semantic understanding for safer social robot navigation

Local VLM Semantic Costmap Layer

A local VLM-style module interprets robot camera frames, combines them with mocked navigation context, and contributes semantic costs for safer social navigation.

The VLM does not control the robot. It converts visual and navigation context into semantic costmap updates. A deterministic planner still makes the final path decision.

Project Overview

  • Semantic intent becomes a 40x40 local costmap, not a robot command.
  • Walking people produce a circular personal-space zone plus a directional predicted-motion zone.
  • Local semantic costs fuse into a 100x100 global demo costmap while hard obstacles stay fixed.
  • A* visualizes baseline versus VLM-enhanced paths for four office hallway moments.
