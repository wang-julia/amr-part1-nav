Qwen2.5-VL semantic understanding for safer social robot navigation

Local VLM Semantic Costmap Layer

A local VLM module interprets robot camera frames, combines them with mocked navigation context, and contributes semantic costs for safer social navigation.

The VLM does not control the robot. It converts visual and navigation context into semantic costmap updates. A deterministic planner still makes the final path decision.

Project Overview

  • Semantic JSON becomes a 40x40 robot-local costmap.
  • Objects are classified as static, possibly moving, or moving before costs are shaped.
  • Every semantic cost is rendered as one or more compact circles.
  • Wall-side groups stay as several wall-side circles so the corridor remains passable.
  • A* visualizes baseline versus VLM-enhanced paths for five robot-photo moments along the T-junction.

How The Metrics Are Calculated

Path length
Total grid-distance from robot/start to goal. Straight steps count about 1; diagonal steps count about 1.4.
Average cost
Mean cost sampled along the selected path. Baseline uses map and wall-padding costs; VLM-enhanced also includes semantic costs.
Social violations
Number of path cells that cross high semantic-cost regions such as person or caution circles.
Risk score
A 0-100 summary of semantic risk from path cost exposure and social violations. Lower is safer.
